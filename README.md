# TaskFlow - PHP Task Management Application

## Project Description

TaskFlow is a simple PHP-based task management application
that allows users to create and view tasks.

The application provides a simple interface for organising
daily activities and keeping track of tasks.

## Features

- Add new tasks.
- Enter task descriptions.
- View all saved tasks.
- Display task creation dates.
- Store tasks in a JSON file.
- Validate submitted information.

## Technologies Used

- HTML
- CSS
- PHP
- JSON

## Requirements

- XAMPP
- PHP 8 or higher
- Visual Studio Code
- Web browser
- Git

## Installation and Setup

1. Install XAMPP.
2. Copy the project folder into the htdocs directory.
3. Start Apache using XAMPP Control Panel.
4. Open the browser.
5. Visit:

http://localhost/SWD414_Week9_Task_Manager/

## Project Structure

SWD414_Week9_Task_Manager/
- index.php
- add_task.php
- style.css
- tasks.json
- README.md

## How to Use

1. Open the application.
2. Enter a task title.
3. Enter a task description.
4. Click Add Task.
5. View the saved task below the form.
